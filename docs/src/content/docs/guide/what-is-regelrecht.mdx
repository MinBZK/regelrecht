RegelRecht is an open-source platform for making Dutch legislation machine-readable and executable. Lawmakers draft in it and government agencies run it. Citizens can inspect how decisions about them are made.

<DocsFeatureCards />

## The problem

Dutch law is published as natural language text. When government agencies need to implement legislation in IT systems, they manually translate legal rules into software. Each agency writes its own interpretation of the same law. Nobody can check whether those implementations match what Parliament intended. Citizens cannot see how decisions about them are made. There is no way to test whether the software follows the law.

## The vision

RegelRecht encodes each law once in a structured format and runs it through a single execution engine. The specification *is* the law. One engine runs it the same way everywhere: in the editor for lawmakers, in the browser for citizens, and in government backends for official decisions. The [architecture overview](./architecture) shows how the corpus, the engine and the tools around them fit together.

## An example

Article 2 of the Wet op de zorgtoeslag says that an insured person is entitled to a healthcare allowance equal to the difference between the standard premium and the normative premium. In RegelRecht that article sits in a YAML file next to its original text, with a `machine_readable` section that states the calculation: derive the normative premium from the income as the Awir defines it, take the standard premium that a ministerial regulation sets each year, subtract the one from the other, and never go below zero.

Ask the engine whether a given person qualifies on 1 January 2025 and it loads the zorgtoeslag law, follows its references into the Awir, the Zorgverzekeringswet and the ministerial regulation, and returns the amount together with a trace naming every article it applied. [How RegelRecht Works](/concepts/how-it-works) walks through that file and that execution step by step.

## Who is this for?

**Developers** building government services that implement Dutch law. Use the engine to compute legal outcomes instead of hand-coding rules.

**Legal experts** validating whether machine-readable interpretations match the law. The [execution-first method](/concepts/methodology) uses concrete test cases from parliamentary documents.

**Policy makers** exploring how legislation works in practice. Run "what if" scenarios in the browser to see how changing a parameter affects outcomes across multiple laws.
