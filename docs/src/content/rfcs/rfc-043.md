This number is held for
[pull request 1630](https://github.com/MinBZK/regelrecht/pull/1630), which
proposes an RFC on lazy evaluation: resolving an input only when an operation
reads it, and executing only the actions a requested output depends on.

See [RFC-000](/rfcs/rfc-000) for why a number is claimed on the default branch
when the pull request opens, rather than when it merges.
