This number is taken. It is held by
[pull request 933](https://github.com/MinBZK/regelrecht/pull/933), which
proposes an RFC on prompt-injection defense for uploaded documents and has been
open in draft since July 2026.

This page exists because the number was almost lost. Two separate branches
claimed RFC-025 within three weeks of each other, neither aware of the other,
because the published sequence jumped from 024 to 026 and read as if 025 were
free. [RFC-000](/rfcs/rfc-000) says a number is never reused once assigned, but
nothing made an assignment visible until its RFC merged, which is exactly the
window in which the collision happens.

A `Reserved` placeholder closes that window. It claims the number on the
default branch on the day the pull request opens, so the next author reads a
sequence with no gaps in it.

## When this page goes away

When [#933](https://github.com/MinBZK/regelrecht/pull/933) merges, it replaces
this file with the real RFC-025, and the reservation has done its job.

If that pull request is closed without merging, this file stays and its status
becomes `Rejected`, because the number is still spent. It does not become free
again: RFC-000 is explicit that a number is never reused, and a reader
following an old link to RFC-025 should find out what happened to it rather
than land on an unrelated document.
