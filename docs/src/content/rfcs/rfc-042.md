This number is held for
[pull request 1298](https://github.com/MinBZK/regelrecht/pull/1298), which
proposes an RFC on modelling bevoegdheid as a resolvable graph.

That pull request currently writes `rfc-036.md`, and it cannot: a different
[RFC-036](/rfcs/rfc-036), on absent and unknown values, was opened later and
merged first. The two documents share nothing but the number. The conflict is
not the author's mistake — RFC-036 was free when they claimed it on 20 August
2026, and nothing on the default branch recorded that claim.

RFC-042 is theirs. Renaming the file in
[#1298](https://github.com/MinBZK/regelrecht/pull/1298) to `rfc-042.md` and
retitling the document resolves the collision and replaces this placeholder.

See [RFC-000](/rfcs/rfc-000) for why a number is now claimed on the default
branch when the pull request opens, rather than when it merges.
