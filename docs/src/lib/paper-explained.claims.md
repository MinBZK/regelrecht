# Claims trace: Rules as Executed, uitgelegd

This file is the claim-by-claim trace from the plain-language explainer page (`/research/rules-as-executed/uitgelegd` and `/explained`) to the position paper "Rules as Executed" as published on 31 August 2026. Each row pairs a claim the page makes (paraphrased from the Dutch source in `paper-explained-content.ts`) with the paper section and the sentence that carries it, and gives a verdict. The paper is frozen; this file and `paper-explained-content.ts` are not, so update the two together: a sentence on the page that has no row here, or whose row is not "supported" or "page's own example", needs either a source in the paper or a rewrite. Verdicts: supported; stronger than paper; unsupported; hedge dropped; page's own example (made-up illustrations, checked only for being labeled as made up).


**Revision.** The first review of the page against the paper flagged the rows marked "rewritten" below. Each of those sentences was rewritten on the page in the same pull request, following the paper sentence quoted in its row; the "Claim on the page" column of those rows still shows the first wording, so the trace records what was corrected. The fidelity review also found omissions (the paper's self-critique in Section 13, intermediaries in Section 6.4, a natural-language authoring layer as "a coherent direction" in Section 10.1, the limit on undeclared gaps in Section 5.4), which the page now covers.
